European SACT Regimen Catalog

A FHIR R4 Implementation Guide that represents systemic anti-cancer therapy (SACT) regimens as executable knowledge artifacts (PlanDefinition, ActivityDefinition, Medication, Library, CodeSystem, ConceptMap). The HemOnc Knowledge Base is the first content source; which further knowledge bases populate the catalog is a later decision.

This IG provides the catalog layer — what to give — that complements the MII Onkologie Modul's recording layer — what was given. Together they close the loop from registry-mandated reporting back to executable clinical-decision support, anchored on a single, openly-licenced source of truth for oncology regimens.

The IG is published in cooperation with HemOnc.org, the OHDSI oncology community, HL7 Europe PHOENIX, and the MII Onkologie working group. See Cooperation, Attribution and Licensing for the full provenance and governance story.

Status

This IG is draft / experimental. The Phase 0 spike (one regimen, Carbo/Paclitaxel Variant #83) is validated end-to-end against the HAPI FHIR Clinical Reasoning engine — see the Phase 0 page. Phase 1A (active + strongly-evidenced HemOnc regimens with experimental MII Onkologie bindings) is in progress.
